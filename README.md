# Boxes App - La Copa

Panel de control de boxes (parrilla de salida), SPEAKER y DNS para jueces.

## Funcionalidades

- **Boxes:** Parrilla de salida, check-in en boxes, subir archivo de boxes
- **SPEAKER:** Anuncios en vivo (nuevo módulo)
- **DNS:** Panel para jueces, consulta de información de corredores
- Log de eventos en vivo

## Deployment

- URL: `boxes.raceclubhub.com`
- Base de datos: Supabase (compartida)

## Setup

```bash
npm install
npm run dev
```
